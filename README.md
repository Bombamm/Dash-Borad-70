หน้าเว็บภาษาไทยพร้อมกราฟโดนัท เลือกเจ้าหน้าที่รวม/รายคน และเลือกยอดส่งการเงินรวม/รายเดือน อ่านเฉพาะชีต บ๋อมแบ๋ม ส้ม ดรีม นุ้ย หนุ่ม จากไฟล์ต้นฉบับ ID `1_mZfQJLd0nvw9twm3vDVl954JvdMwBXyULrqGypUbok` ไม่มีการเขียนกลับชีต

## เปิดบน GitHub Pages

1. Settings → Pages → Deploy from a branch → main → /(root) → Save
2. หน้าเว็บจะเปิดได้ที่ URL ที่ GitHub แสดงใน Pages (การอัปโหลดซอร์สเพียงอย่างเดียวยังไม่เปิด Pages)
3. หากต้องการอ่านข้อมูลสดบน GitHub Pages ให้สร้าง OAuth client ชนิด Web application ใน Google Cloud เปิด Google Sheets API และตั้ง Authorized JavaScript origins เป็น `https://bombamm.github.io` ตั้ง OAuth consent screen และผู้ทดสอบตามประเภทบัญชี
4. กรอก Client ID ในส่วน “เชื่อมต่อข้อมูลและวิธีนับยอด” แล้วเข้าสู่ระบบ Google ด้วยบัญชีที่อ่านไฟล์ต้นฉบับได้ สิทธิ์ที่ขอเป็น spreadsheets.readonly ไม่มี client secret ในเว็บ

ตั้งค่า OAuth Client ID ไว้แล้ว หน้าเริ่มต้นรอเชื่อมต่อ Google Sheets โดยไม่เผยแพร่ข้อมูลจริงลงใน repository สิทธิ์เชื่อมต่อจำใน sessionStorage ของแท็บจนหมดอายุ รีเฟรชแท็บเดิมจึงใช้สิทธิ์เดิมได้

## ทางเลือก: เปิดจาก Google Apps Script โดยตรง

1. ในไฟล์ต้นฉบับเลือก Extensions → Apps Script
2. วาง `Code.gs` และเพิ่ม HTML file ชื่อ `Dashboard` จากเนื้อหา `Dashboard.html`
3. Deploy → New deployment → Web app ตั้ง Execute as เป็น User accessing the web app และจำกัดกลุ่มผู้เข้าใช้ตามหน่วยงาน ห้ามเผยแพร่แบบ execute as owner ให้ผู้ไม่มีสิทธิ์ไฟล์
4. เปิด URL /exec และอนุญาตการอ่านไฟล์ ระบบจะดึงข้อมูลจริงทันที กดอัปเดตข้อมูลเพื่ออ่านใหม่

Apps Script เป็นทางเลือกในการเปิดเว็บ ไม่ใช่ endpoint สาธารณะสำหรับ GitHub Pages

## ความหมายข้อมูล

- อ่านชื่อหัวคอลัมน์แถว 4 ของแต่ละชีตโดยตรง ข้อมูลเริ่มแถว 5 รองรับการสลับคอลัมน์ และหยุดแสดงยอดใหม่หากหัวคอลัมน์ที่จำเป็นหายไป
- วงเงินงบประมาณและวงเงินตกลงจ้างนับตามสัญญาไม่ซ้ำ ยอดคงเหลือ = วงเงินงบประมาณ − วงเงินตกลงจ้าง
- ผู้รับจ้างและเลขที่สัญญา/ใบสั่งจ้างแยกกัน รักษาเลขศูนย์นำหน้าตามที่แสดงในชีต
- กราฟงบประมาณ/หมวดหมู่/วิธีจัดจ้างเป็นสัดส่วนวงเงินตกลงจ้าง ไม่ใช่จำนวนรายการ
- เลขสัญญาเดียวกัน (ตัดช่องว่าง/ไม่แยกตัวพิมพ์) นับฉบับเดียว ใช้วงเงินจากแถวแรก หากยอดต่างกันมีข้อความเตือน ควรตรวจเลขที่สัญญาให้เป็นเอกลักษณ์ข้ามเจ้าหน้าที่
- แถวที่ยังไม่มีเลขสัญญายังรวมวงเงิน แต่ไม่นับเป็นสัญญาที่ออกแล้ว ยอดส่งการเงินรวมทุกแถวเนื่องจากอาจเป็นคนละงวด ไม่ใช้วงเงินสัญญาแทนยอดส่ง
- เดือนคำนวณจากหัวคอลัมน์วันที่ส่งการเงินเท่านั้น เดือนกรองเฉพาะยอดส่งการเงินและรายการประกอบ ไม่เปลี่ยนวงเงินสัญญารวม
- สูตรเดิมที่ใช้ TODAY() ในตารางเดิม ไม่ถือเป็นวันที่ส่งการเงิน ยอดที่ไม่มีวันที่แสดงใน “ไม่ระบุเดือน” และยังรวมในยอดทั้งหมด
- วันที่ตัวเลขรับช่วง ค.ศ. 2000–2100 ข้อความรองรับ dd/mm/yyyy พ.ศ./ค.ศ. และ ISO yyyy-mm-dd วันที่ผิดไม่เดาแทน
- ไม่อ่านทะเบียนรับงาน และไม่แก้ข้อมูลต้นฉบับ
